# Модуль распознавания документов

Модуль обрабатывает фотографии и сканы бумажных форм СНИЛС: находит документ, оценивает качество, подготавливает изображение, читает текст и возвращает структурированные поля с происхождением и диагностикой. Разработчик модуля – Дмитрий Алексеев. Редакция архитектуры – 0.4.

СИРД является внешней системой по отношению к модулю. Ее авторизация, пользовательский интерфейс, очередь, база заданий, предметный каталог и публикация окончательного ответа находятся за границей описания. Для интеграции определены только необходимые входы, выходы и зависимости.

## Состояние спецификации

Документы описывают проектируемый модуль. ADR имеют статус `proposed`; измеренные результаты и выбранная по испытаниям модель пока не представлены. Численные параметры рабочего окружения задаются профилем запуска; численные критерии качества фиксируются до итогового испытания. Требования хранятся в SRS, методы их проверки связаны в [таблице трассируемости](requirements/traceability.md).
