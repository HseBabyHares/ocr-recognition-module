# Smart garbage collector

The collector is a read-only detector and proposal generator. It combines deterministic sensors, normalized fingerprints, an accepted-debt baseline, recurrence history, and bounded harness-improvement proposals. It does not autonomously redesign the product, edit architecture policy, waive a scanner, weaken an oracle, or merge cleanup changes.

Scheduled runs publish inventory and proposals. A cleanup agent receives one coherent cluster, verifies before/after evidence, and opens a reviewable change. Recurring validated fingerprints become candidates for a new lint rule, structural test, hook, fixture, skill correction, or diagnostic improvement after human approval.
