# Метрики OCR и правила расчета

## 1. Общие обозначения

Все метрики привязаны к версии корпуса, варианту и режиму. `R` – применимые, присутствующие и читаемые по эталону поля. `U` – применимые поля с недоступным чтению содержимым: присутствующее нечитаемое значение либо недоступная область, где присутствие неизвестно. `A` – применимые поля с доступной областью и подтвержденным отсутствием значения. `K` – неприменимые по форме поля. `N` – кадры без целевого документа. Спорные поля `disputed` анализируются по заранее заданному правилу; их число сообщается отдельно. Для поля i: `a_i=1`, если выбранное значение выдано; `c_i=1`, если выданное значение точно совпадает с эталоном по зафиксированной нормализации. Иначе индикатор равен 0.

Состояния системы не изменяют принадлежность к R или U. Пометка `not_applicable`, выставленная ошибочно самой системой, не удаляет пример из знаменателя. Технический отказ на читаемом поле дает `a_i=0, c_i=0`. Отсутствующая запланированная запись блокирует расчет, пока не восстановлен технический исход.

Любое отношение сохраняет числитель и знаменатель. При нулевом знаменателе значение равно null с причиной. Повторы и снимки одного документа не считаются независимыми наблюдениями для доверительного интервала.

## 2. Поля и отказ от выдачи

| Метрика | Формула | Интерпретация |
|---|---|---|
| Точное извлечение читаемого поля | `sum_R(c_i) / |R|` | Отказ и техническая ошибка снижают результат |
| Покрытие читаемых полей | `sum_R(a_i) / |R|` | Какая часть пригодных полей получила значение |
| Ошибка среди выданных читаемых полей | `sum_R(a_i*(1-c_i)) / sum_R(a_i)` | Условный риск выбранных значений |
| Неподдержанная выдача | `sum_U(a_i) / |U|` | Значения на полях, которые не читаются по данному входу; это не обязательно несовпадение с известным номером |
| Выдача в пустом поле | `sum_A(a_i) / |A|` | Ошибочное заполнение доступной пустой области |
| Выдача неприменимого поля | `sum_K(a_i) / |K|` | Реквизит, которого не предполагает форма |
| Выдача полей на кадре без цели | `count_N(есть выбранное целевое поле) / |N|` | Отдельная ошибка отрицательного входа |
| Полный успех читаемого документа | `count(все три поля правильны) / count(документы с тремя читаемыми полями)` | Частичные документы анализируются отдельно |

Метрики выводятся отдельно для snils, full_name и birth_date, каждой формы, класса качества и источника данных. Среднее по трем формам вычисляется при ненулевом знаменателе каждой формы и дает им равный вес. Итог по смешанному потоку допустим только при заранее объявленных весах; высокая доля простых кадров не скрывает сложную форму.

Для частичных документов отдельно учитываются правильные доступные поля и неподдержанная выдача на недоступных. Критерий пригодности итогового ответа для процесса ВШЭ в эти метрики не входит.

## 3. Ошибка текста

Ошибка символов (CER) равна `(S+D+I)/L`, где S, D и I – замены, удаления и вставки при минимальном редакционном выравнивании, L – число символов эталона. Для корпуса используется сумма числителей и сумма L. Эта доля может превышать 1 при большом числе вставок.

Версия алгоритма выравнивания и нормализации текста фиксируется. Для пустого эталона значение CER отдельно не определяется; вставки на таком входе учитываются как ложный текст. Отсутствие ответа на непустом эталоне дает удаления всех эталонных символов. CER не заменяет точное совпадение номера и имени.

## 4. Детекция, форма и геометрия

Предсказанные и эталонные объекты сопоставляются взаимно однозначно по максимальному суммарному пересечению областей (IoU) с заранее заданным порогом. Повторные детекции одного объекта не становятся несколькими истинными успехами. Выбор формы оценивается после сопоставления отдельно от геометрии.

| Метрика | Расчет |
|---|---|
| Полнота поиска | Сопоставленные целевые объекты / все размеченные видимые целевые объекты |
| Точность поиска | Сопоставленные объекты / все выданные целевые кандидаты |
| Ложное обнаружение на отрицательном кадре | Кадры без цели с детекцией / все кадры без цели |
| Правильная форма | Верно определенные формы / все положительные объекты, где форма различима по кадру; неразрешенный результат остается в знаменателе |
| Ошибка углов | Среднее расстояние в координатах оригинала по видимым сопоставленным углам, в пикселях и долях диагонали |
| Покрытие углов | Найденные размеченные видимые углы / все размеченные видимые углы |
| Потеря области поля при обрезке | `|M \ V| / |M|`, где M – видимая эталонная маска поля в оригинале, V – сохраненная область исходных пикселей |

Ошибка углов всегда сопровождается покрытием: отсутствие сложных углов не должно улучшать единственное среднее. Четверти оборота оцениваются классификацией ориентации, остаточный угол – отдельно в градусах. Для неизвестной ориентации сообщается доля отказов. Невидимые области исходного кадра не входят в M и не считаются потерянными самой обрезкой.

## 5. Качество и диагностические причины

Для заявленных дефектов считаются precision и recall по размеченным областям и заранее заданному правилу совпадения. Белое поле без закрытого текста включается как отрицательный пример для подозрения на блик. Отсутствующее измерение учитывается отдельной долей.

Согласие общих уровней качества оценивается только по заранее заданной матрице допустимых сочетаний. Q4 может содержать частично читаемые поля, поэтому доля Q4, объявленных пригодными целиком, не заменяет полевую метрику неподдержанной выдачи.

## 6. Вклад преобразований и корректора

На общих примерах сравниваются базовое b_i и новое n_i значения. Пусть `B` – читаемые поля, правильные в базе. Порча правильного поля равна `count_B(новое неверно или отсутствует)/|B|`. Для `W=R \ B` доля полезных изменений равна `count_W(новое значение правильно)/|W|`. Публикуются оба отношения и абсолютные количества, чтобы различие размеров B и W не скрывало итоговый эффект.

Для коррекции отдельно задается множество содержательно измененных читаемых полей `C=changed ∩ R`. Точность исправлений – число правильных итоговых значений в C / |C|. Измененные поля из U, A и K учитываются отдельными показателями неподдержанной выдачи; известное по другому оригиналу значение не переносит поле в C. Правильные неизмененные поля в эту долю не входят. Форматирование даты и разделителей номера учитывается отдельно от изменения предполагаемых символов.

Обязательно выводятся переходы «верно → верно», «верно → ошибка/отказ», «ошибка/отказ → верно», «ошибка/отказ → ошибка/отказ». Улучшение среднего CER не скрывает вред для точных персональных полей.

## 7. Уверенность

Некалиброванный score не является вероятностью. Для калиброванной вероятности p_i и правильности y_i Brier равен `sum((p_i-y_i)^2)/n`. Указываются задача калибровки, набор, модель, профиль и версия отображения. Отказ от значения и применение порога не должны менять определение y_i задним числом.

Таблица по заранее заданным диапазонам показывает число примеров, среднюю вероятность и фактическую правильность. Дополнительно строится зависимость риска от покрытия. Пустой диапазон остается неоцененным. Калибровка одной модели или формы не считается применимой к другой без проверки.

## 8. Время и память

Время полного вызова измеряется от доступного модулю входа до завершенного результата, включая преобразования, все OCR-повторы, коррекцию и сборку. Загрузка весов и прогрев либо включены и помечены как холодный режим, либо измерены отдельно. При асинхронном устройстве момент конца соответствует фактическому завершению вычисления.

Публикуются число запланированных, начатых, завершенных и завершенных в срок вызовов; технические исходы; P50/P95 завершенных вызовов; пиковая память и устройство. Процентили только успешных вызовов явно условны. Остановленный по лимиту вызов не получает выдуманную истинную задержку, равную лимиту; это время фактического ожидания и отдельный технический исход; для времени успешного завершения известно только, что к пределу результат не был получен. При значимой доле остановок нельзя объявлять P95 всего потока по оставшимся успешным вызовам.

## 9. Неопределенность оценки

Сравнения парные: для каждого исходного примера есть оба варианта. При повторной выборке пересэмплируются группы происхождения целиком вместе со всеми снимками и вариантами, затем пересчитывается разность метрик. Способ, число повторных выборок и семя фиксируются в протоколе.

Нулевая наблюдаемая частота ошибки не доказывает нулевой риск. Для независимых групп с бинарным событием «в группе есть хотя бы одна ошибка» и нулем событий односторонняя верхняя граница уровня `1-alpha` равна `1-alpha^(1/G)`, где G – число групп. Ее нельзя без изменения определения переносить на зависимые поля или снимки. Если независимости или объема недостаточно, статистический вывод ограничивается описанием выборки.
