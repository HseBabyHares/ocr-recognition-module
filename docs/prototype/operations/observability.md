# Диагностика и измерения исполнения

## 1. Событие стадии

Для начала и завершения стадии фиксируются request_id, attempt_id, stage_id, implementation_id/version, spec_hash, время, outcome и безопасный код причины. В эксперименте дополнительно записываются run_id, sample_id, variant_id и repeat_id. Персональные реквизиты и полномочия доступа не являются метками телеметрии.

## 2. Измерения

| Показатель | Единица | Область |
|---|---|---|
| Длительность стадии и вызова | мс | Монотонное время, включая разрешенные повторы |
| Процессорное время | мс CPU | Процесс/группа процессов; метод сбора указан |
| Пиковая память | байты | Отдельный процесс или вся выделенная группа |
| Вызовы моделей и варианты изображения | число | Полный расход текущей операции |
| Технические исходы | число | Ошибка, лимит, отмена, успешное завершение |
| Исходы поиска | число | detected, not_detected, uncertain; отдельно от ошибок |
| Состояния полей | число | extracted, absent, unreadable, conflict, not_processed |
| Попадания в кеш | число | Отдельно от фактического вычисления |

Пики памяти нескольких процессов не суммируются произвольно по несовпадающим моментам времени: либо измеряется общая группа, либо метод и его ограничение отражаются явно. Внутренние оценки уверенности не заменяют измеренную точность полей без эталона.

## 3. Диагностические материалы

Связь поля с изображением проверяется через защищенный доступ к материалу и координатам. Текст не дублируется в исключениях или логах. Диагностический режим ограничен сроком и кругом доступа; по умолчанию постоянная запись промежуточных изображений отключена.

## 4. Признаки проблем

Рост limit_exceeded требует проверки размеров входа, числа вариантов, потоков и памяти. Рост ошибок модели требует проверки доступности весов и версий. Изменение распределения confidence само по себе не доказывает регрессию: нужен размеченный контрольный набор. Повторяющиеся uncertain могут означать другую форму или качество фотографий и разбираются по обезличенным метрикам и разрешенным примерам.

Действия при превышении лимита – [RB-OCR-001](runbooks/RB-OCR-001-execution-limits.md). Разбор регрессии – [RB-OCR-002](runbooks/RB-OCR-002-regression.md).
