# Условная предобработка с исходным вариантом

## Контекст

Обнаружение границы и улучшение изображения могут испортить читаемые поля. Универсальный порог дефекта и один набор фильтров для трех форм не обоснованы измерениями.

## Рассмотренные варианты

| Вариант | Выигрыш | Ограничение |
|---|---|---|
| Всегда применять общий набор фильтров | Одинаковая цепочка | Лишние преобразования и потеря деталей |
| Управляемые операции и путь без улучшений | Можно измерить вклад каждой операции | Нужны профиль, диагностические условия и проверка геометрии |

## Предлагаемое решение

Сохранять оригинал, историю преобразований и ограниченный путь без необязательных улучшений. Геометрия допускается при проверяемых основаниях. Повторное чтение и варианты регулируются общим бюджетом.

## Обоснование и последствия

Сравнение включает улучшение и порчу полей при фиксированном OCR. Конкретные детекторы, интерполяции и пороги выбираются по эксперименту; решение не назначает победителя.
