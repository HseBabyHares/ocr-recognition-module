# Architecture evidence gate

The repository declares which views are mandatory and which code-change triggers require deployment, sequence, state, or data-model views. C4/Structurizr is recommended for structural views; DFD is required for trust and data-flow analysis. UML/PlantUML/Mermaid views remain conditional evidence, not a universal checkbox.

Freshness is derived from changed-path-to-component mappings, artifact regeneration, reference integrity, and exact no-impact assessments. File timestamps alone are not proof of currency.
