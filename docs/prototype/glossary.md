# Глоссарий модуля

| Термин | Значение в модуле |
|---|---|
| Оптическое распознавание символов (OCR) | Получение текста из изображения. OCR-движок является одной стадией модуля. |
| OCR-модуль | Совокупность подготовки изображения, поиска документа, распознавания, обработки полей и интерфейсов исполнения. |
| Форма документа | Один из поддерживаемых макетов: старая карточка СНИЛС, АДИ-РЕГ 2019, АДИ-РЕГ 2023. |
| Кандидат документа | Область изображения и гипотезы о ее типе. Обнаруженная область еще не подтверждает форму или подлинность. |
| Область интереса (ROI) | Часть растра с явно указанной системой координат. |
| Наблюдение | Текст, область, оценка качества или признак, непосредственно полученные конкретной реализацией. |
| Гипотеза поля | Предложенное значение со ссылками на наблюдения. |
| Нормализация | Разрешенное преобразование представления без замены предполагаемого содержания. |
| Коррекция | Предложение заменить распознанный символ или фрагмент. Изменение требует отдельного основания. |
| Формальная проверка | Проверка формата, календарной допустимости или контрольного числа. Ее успех не доказывает соответствие изображению. |
| Исходная оценка (score) | Число в шкале определенного алгоритма; не обязательно вероятность правильности. |
| Калибровка | Полученное на выделенных данных отображение оценок в вероятность для определенной задачи и конфигурации. |
| Отказ от значения | Явное отсутствие выбранного значения при недостаточных либо противоречивых наблюдениях. |
| Производный материал | Изображение или наблюдение, связанные с исходником и примененными преобразованиями. |
| Профиль исполнения | Неизменяемый набор стадий, реализаций, настроек, ограничений и правил остановки. |
| Группа происхождения | Связанные снимки, документы одного человека при известной связи и производные изображения; группа используется при разделении данных. |
| Базовый вариант | Зафиксированная конфигурация, с которой сравнивают другие варианты. |
| Поэтапное исключение компонентов (ablation) | Сравнение конфигураций с отключением или заменой определенной стадии. |
| Сквозное испытание | Запуск от исходного изображения до полей без подстановки эталонной формы, границ и значений. |
| Компонентное испытание | Проверка одной стадии на контролируемом входе. Подстановка правильных границ разрешена только в явно указанном компонентном режиме. |
| Оценщик | Программа, которая сопоставляет сохраненные результаты с эталоном и вычисляет метрики; не входит в рабочий путь распознавания. |
| План эксперимента | Перечень сравниваемых конфигураций, данных, измерений и правил выбора до просмотра итоговых результатов. |

`request_id` обозначает корреляцию вызова модуля. `run_id` обозначает конкретный эксперимент. `artifact_id` обозначает конкретный материал, а его контрольная сумма проверяет содержимое.
