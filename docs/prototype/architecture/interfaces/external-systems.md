# Внешние зависимости модуля

## Вызывающая часть СИРД

Предоставляет разрешенные материалы, техническую политику, выбранный кандидат и скомпилированный профиль. Принимает наблюдения и структурированные поля, применяет свои критерии достаточности и публикует результат. Модуль не получает прямой доступ к таблицам заданий и не подтверждает доставку сообщения брокера.

## Поставщик материалов

`MaterialReader` открывает только разрешенные ссылки текущего вызова и проверяет размер/сумму. Для разработки он может читать файлы выделенного каталога; в интеграции – обращаться к предоставленному хранилищу. Тип хранилища не меняет вычислительный контракт. Недоступность возвращается как ошибка материала.

## Реестр реализаций

Содержит разрешенные версии декодеров, детекторов, OCR и корректоров. Рабочий вызов может выбрать только объявленный идентификатор. Правила использования, доступность весов и поддержка нужного устройства проверяются перед включением кандидата в эксперимент. Выбор по названию продукта без версии недостаточен.

## Среда исполнения

Предоставляет ограниченный процесс, локальные веса и временную рабочую область. Вызов не требует сетевого доступа к публичным моделям. Недоступный ускоритель не заменяется другим устройством без новой конфигурации.

## Испытательное приложение

Подает план, запускает рабочие порты и сохраняет предсказания. Оценщик имеет отдельный доступ к эталону. Система разметки, публикация статьи и трекер команды не входят в рабочий модуль; данные для них выгружаются по правилам эксперимента и защиты материалов.
