# DFD and STRIDE gate

The canonical inputs are machine-readable DFD elements, data flows, trust zones/boundaries, complete STRIDE coverage, threat records, controls, verification references, owners, and expiring human risk decisions. Rendered diagrams are derived views and cannot be used as the sole source of truth.

Every network or integration project must map changed code paths to architecture components. A cross-zone flow without a trust boundary, an uncovered STRIDE category, an unexplained `not-applicable`, an unverified mitigation, or an expired accepted risk fails the deterministic gate before any LLM review runs.
